# Interview-Ace
🎙️ AI-powered real-time interview assistant with dual-agent voice recognition and smart Q&amp;A generation.

Interview Ace is an open-source, dual-agent AI assistant designed to help candidates navigate online interviews in real time.
Agent 1 handles knowledge management — it ingests job descriptions, fetches role-specific resources, and generates contextual answers using RAG + your choice of LLM (Claude, GPT, Gemini, DeepSeek, and more).
Agent 2 handles voice — it learns to distinguish the candidate's voice from the interviewer's, transcribes questions in real time, and passes them to Agent 1 for response generation. Candidates can rephrase unclear questions aloud; the system picks it up automatically.
